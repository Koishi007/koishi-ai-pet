# 决策记录（ADR）

这里记录**为什么这么做** - 那些从代码里读不出来、但改动时又必须知道的设计取舍。
「怎么做」在 [architecture.md](../architecture.md) 与 [subsystems/](../subsystems/) 里。

## 新增时机

- 改动会让未来的维护者问「为什么要这样」时；
- 在两个都可行的方案之间做了取舍时；
- 因为外部约束（缓存、性能、平台差异、历史包袱）而选择看起来不直观的做法时。

一条记录包含：状态、背景、决定、后果（含代价）、相关代码。格式沿用现有条目，
文件名 `NNNN-短标题.md`。
